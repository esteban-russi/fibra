# CLAUDE.local.md

Personal, non-checked-in instructions for this repo. Not committed — see `.gitignore`.

## Committing

- After completing a task, **ask whether to commit** — never commit unprompted.
- State **which branch** the commit would land on, and flag it explicitly when that branch is `main`.
- Commit **under the user's name only**. Do not add `Co-Authored-By: Claude ...` or any other Claude attribution trailer to commit messages. This overrides the harness's default attribution guidance.
